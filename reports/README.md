## iPhone 下载与阅读

### 方式一：PDF（推荐）

1. 在 Cursor / GitHub 中打开 `reports/越疆科技财报与股价分析报告.pdf`
2. 点击下载或「在文件中打开」
3. 保存到「文件」App 后，可用预览、Books 或 WPS 阅读

### 方式二：Safari 打开 HTML

1. 用 Safari 打开 `越疆科技财报与股价分析报告.html`
2. 点击分享 →「存储到文件」

### 方式三：重新生成 PDF

```bash
python3 scripts/generate_dobot_report.py
```
